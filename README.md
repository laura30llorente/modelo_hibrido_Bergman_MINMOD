# modelo_hibrido_Bergman_MINMOD
Trabajo de Fin de Grado de Ingeniería del Software: Diseño, implementación y validación de un modelo híbrido basado en el Modelo Mínimo de Bergman, con la finalidad de mejorar la capacidad de predicción incorporando una red neuronal para estimar el parámetro que determina la capacidad de la insulina para aumentar la captación de la glucosa.
